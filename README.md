# 单词小栈 · Word Hut

纯网页、零构建、可离线的背单词小游戏。**打开网址即可玩**：

> https://flygon611.github.io/English-learning-flygonish/

## 玩法

- **四选一闯关**：5 关连闯，答错扣命，连击加成
- **翻卡记忆**：翻面自评，自动安排复习间隔
- **拼写填空**：键盘输入或字母点选，拼错逐字提示

## 词库

内置六套：四级 / 六级 / 专四 / 专八 / 雅思 / 托福，共 40,925 词。
每套都能**按首字母拆分**单独练（例如「专四 · A 开头」），
也可以在「词库」页**导入自己的词表**。

## 关于本仓库

这个仓库是**构建产物**，由本地脚本生成后推送，所以不要在网页上直接改这里的文件。

```
构建脚本 : tools/build_gh_pages.py
产物结构 : index.html · style.css · js-src/ · data/ · vocab/ · audio/ · ui/
```

学习进度存在浏览器 localStorage，不上传服务器；换设备/清缓存会从头开始，
可在「统计」页导出进度 JSON 备份。
